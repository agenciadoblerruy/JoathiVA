# Manual de Usuario Proveedor

## Acceso

- Usuario demo: `admin`
- Clave demo: `Joathi2026!`
- URL: [http://localhost:8787](http://localhost:8787)

## Que puede hacer

- registrar choferes,
- registrar transportes,
- publicar viajes,
- informar costo proveedor,
- cargar datos bancarios al registrarse,
- iniciar tracking GPS,
- registrar hitos de operacion,
- ver pedidos compatibles con sus destinos,
- revisar recibos de liquidacion.

## Alta inicial recomendada

1. Completar datos de usuario.
2. Informar datos bancarios para transferencia.
3. Registrar choferes.
4. Registrar unidades.
5. Publicar viajes disponibles.

## Operacion del viaje

Desde `Viajes` el proveedor o chofer puede registrar:

- comienzo de operacion + GPS,
- comienzo de viaje,
- llegada,
- finalizacion de descarga.

## Pedidos por destino

En el home del proveedor aparece un panel con:

- pedidos de clientes asociados al destino de sus viajes,
- monto,
- peso,
- volumen,
- ruta,
- estado comercial.

## Liquidacion

Al finalizar una operacion el sistema genera un recibo con:

- numero de recibo,
- monto a liquidar,
- banco,
- cuenta,
- estado del pago.

## Nota importante

Si el proveedor no informa sus datos bancarios, el alta queda incompleta para cobro operativo.
