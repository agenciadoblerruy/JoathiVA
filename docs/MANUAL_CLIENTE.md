# Manual de Usuario Cliente

## Acceso

- Usuario demo: `cliente`
- Clave demo: `Cliente2026!`
- URL: [http://localhost:8787](http://localhost:8787)

## Que puede hacer

- ver viajes disponibles,
- solicitar un viaje,
- revisar el calculo comercial,
- seguir la mercaderia en tiempo real,
- consultar historial,
- subir documentos al repositorio,
- ver datos de facturacion cuando la operacion finaliza.

## Como solicitar un viaje

1. Ingresar al portal.
2. Ir a `Solicitar viaje`.
3. Elegir un viaje publicado.
4. Completar carga, peso, volumen y adicionales.
5. Confirmar el pedido.

## Seguimiento

Cuando el proveedor inicia la operacion, el cliente puede ver:

- carga,
- comienzo de viaje,
- llegada,
- descarga,
- GPS de la unidad,
- estado de cobro.

## Historial

El perfil cliente separa:

- `Pedidos solicitados`
- `Pedidos finalizados`

## Repositorio

El cliente puede cargar:

- permisos de aduana,
- declaratoria,
- factura,
- remito,
- otros adjuntos.

## Facturacion

Al finalizar la operacion se muestra:

- referencia de factura,
- razon social,
- documento,
- subtotal,
- IVA,
- total.
