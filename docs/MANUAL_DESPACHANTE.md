# Manual de Usuario Despachante

## Acceso

- Usuario demo: `despachante`
- Clave demo: `Despachante2026!`
- URL: [http://localhost:8787](http://localhost:8787)

## Que puede hacer

- ver operaciones en curso,
- revisar estados del viaje,
- consultar tiempos operativos,
- acceder a la documentacion subida,
- seguir el avance documental y aduanero,
- recibir notificaciones operativas.

## Panel del despachante

El panel muestra:

- cliente asociado,
- ruta,
- estado del viaje,
- tiempo de carga,
- comienzo de viaje,
- llegada,
- descarga,
- estado de facturacion,
- total operativo.

## Repositorio aduanero

El despachante puede consultar documentos asociados a pedidos, por ejemplo:

- permiso de aduana,
- declaratoria,
- factura,
- remito,
- otros adjuntos.

## Uso recomendado

1. Entrar al panel del despachante.
2. Revisar operaciones activas o con documentos pendientes.
3. Descargar la documentacion necesaria.
4. Seguir las alertas y los hitos del viaje hasta cierre.

## Alcance actual

El despachante hoy tiene perfil de consulta y seguimiento.

No publica viajes ni genera pedidos.
