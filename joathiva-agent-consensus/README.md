# JoathiVA Agent Consensus

Sistema de consenso para coordinar decisiones con 3 agentes y aprobacion humana final.

## Participantes

- Agent 1: Arquitectura y Backend
- Agent 2: Base de Datos y Seguridad
- Agent 3: Producto, Operaciones y UX
- Rodrigo Hernandez: aprobacion final

## Regla principal

No se implementa ningun cambio hasta que existan devoluciones de los 3 agentes, no haya bloqueantes criticos abiertos y Rodrigo apruebe el avance.
