# Reglas de consenso JoathiVA

## Participantes

- Agent 1: Arquitectura y Backend
- Agent 2: Base de Datos y Seguridad
- Agent 3: Producto, Operaciones y UX
- Rodrigo Hernandez: aprobacion final humana

## Regla de avance

Una propuesta solo puede avanzar si cumple todo lo siguiente:

- Los 3 agentes dejaron devolucion.
- Ningun agente mantiene un bloqueante critico abierto.
- Existe una decision final documentada.
- Rodrigo aprobo explicitamente el avance.

## Bloqueo critico

Si cualquier agente marca bloqueante critico, la propuesta no avanza.

El bloqueo debe resolverse, documentarse y volver a revisarse.

## Cambios obligados a pasar por consenso

- Produccion.
- Base de datos MySQL.
- API.
- APK Android.
- Permisos de SMS, llamadas, GPS o seguridad.
- Estados operativos de choferes.
- Notificaciones operativas.
- Margenes, tarifas o logica comercial.

## Resultado posible

- Aprobado.
- Aprobado con cambios.
- Rechazado.
- En revision.
